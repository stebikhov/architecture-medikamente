# architecture-medikamente
Проектная работа 10-го спринта по архитектуре «Медикаменте»: работа с конфиденциальными данными, целевая архитектура в C4 с Privacy by Design, единая классификация C1-C6, средства защиты, диаграмма Исикавы с 23 приоритизированными мерами, план переключения и движок классификации данных до загрузки в хранилище.
